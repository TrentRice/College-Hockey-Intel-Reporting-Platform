Generated by [`src/evaluation/validate_chn_data.py`](../src/evaluation/validate_chn_data.py) from the CSVs in `data/processed/chn/`. The data itself isn't in this repo: College Hockey News allows personal, non-commercial use only (see [docs/schema.md](schema.md#data-source-and-use)). To reproduce this report, build the data with the scrapers (see the README), then run `make validate`.

Covers 2 seasons (2025-26 to 2026-27), 1,316 box scores.

**16 of 16 exact checks have no unexplained mismatches.** 5 rows differ because the College Hockey News page itself is inconsistent; each is listed under [Source errors](#source-errors) with a link to the page. No row is unexplained.

## Approximate checks
